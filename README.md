# Rivermax Dev Kit + NvNmos C API Example

A standalone C++17 example that combines the
[Rivermax Dev Kit](https://github.com/NVIDIA/rivermax-dev-kit) data plane with
the [NvNmos](https://github.com/NVIDIA/nvnmos) C API control plane. One
application hosts an NMOS Node with SMPTE ST 2110-20 video, ST 2110-30 audio
and ST 2110-40 ancillary data Senders and Receivers, with optional
SMPTE ST 2022-7 redundancy, and applies IS-05 activations to each of them.

The repository does not yet contain any code. Build and usage instructions
will be added with the application.
